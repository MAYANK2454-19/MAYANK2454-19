### 🔍 Overview

CyberSentinel is a growing collection of cybersecurity utilities designed to simplify common reconnaissance, security analysis, and web assessment tasks.

The goal of the project is to make frequently used security checks accessible through a clean web interface while helping developers and students understand the information being presented rather than simply displaying raw outputs.

---

### ✨ Features

- 🔐 Security Header Checker
- 🌍 DNS Lookup
- 👤 WHOIS Lookup
- 🔒 SSL Certificate Inspector
- 🌐 HTTP Header Analyzer
- 🔗 URL Analyzer
- 📊 Easy-to-read reports
- ⚡ Fast API-based lookups
- 💻 Responsive UI
- 🚀 Railway Deployment
